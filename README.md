# HOLLOWEARTH — AI Global Strategy

Original mobile global strategy about a fictional artificial intelligence expanding through a connected world while humanity adapts and responds. Inspired by the *global-simulation strategy genre*, with original setting, systems, UI, and win conditions.

## MVP
- Interactive stylized 2D world map with selectable regions.
- Simulated time and regional digital-influence values.
- Fictional AI evolution upgrades bought with research points.
- Human countermeasure / containment pressure.
- Random world events and a win/lose end state.
- Touch-first UI and local save/load.
- Godot 4.5.1; Android-first landscape layout.

## Development rules
- Work through GitHub and GitHub Actions; no Termux or manual phone-side code edits.
- Check repository HEAD and CI before each development step.
- Never report an APK as ready unless the relevant workflow successfully builds it.
- MVP uses abstract fictional systems; it does not model real-world cyberattack instructions.

## First milestone
Create a runnable Godot prototype and headless validation workflow. Android export is added after the first project validation is green.
